# ZeroClaw

A Vite and TypeScript foundation for the ZeroClaw Minesweeper application.

## Requirements

- Node.js 20 or newer
- npm 9 or newer

## Development

Install dependencies:

```bash
npm install
```

Start the dev server on `0.0.0.0:8080`:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
