# ZeroClaw

ZeroClaw is a Vite and TypeScript Minesweeper application with unit and
end-to-end coverage.

## Requirements

- Node.js 20 or newer
- npm 9 or newer

## Development

Install dependencies:

```bash
npm install
```

Start the dev server on `0.0.0.0:8080`:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Verification

Run the full local verification suite before deploying:

```bash
npm run test
npm run lint
npm run format:check
npm run build
npm run test:e2e
```

The production build is generated by `npm run build`, which runs
`tsc --noEmit` before `vite build`.

`dist/index.html` references hashed assets with root-relative paths such as
`/assets/index-VWj4NaW6.js` and `/assets/index-DhLgLPFN.css`. Serve `dist/`
from the site root so these paths resolve correctly. If the app must be hosted
under a subpath, configure Vite's `base` option before building.

## Self-Hosted Deployment

Build the app:

```bash
npm ci
npm run build
```

Copy the generated `dist/` contents to the web root:

```bash
sudo mkdir -p /var/www/zeroclaw
sudo rsync -a --delete dist/ /var/www/zeroclaw/
```

Sample Nginx server block:

```nginx
server {
    listen 80;
    server_name example.com;

    root /var/www/zeroclaw;
    index index.html;

    location /assets/ {
        try_files $uri =404;
        access_log off;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

Reload Nginx after installing the site config:

```bash
sudo nginx -t
sudo systemctl reload nginx
```
